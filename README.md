# LapsaBarber: сайт-демо для Laura

Статический сайт без сборки: `index.html` + `css/` + `js/` + `img/` + `fonts/` + `content.json`.
Папку целиком можно перетащить в Netlify.

## Дизайн-план

**Главная идея: «срез бритвы».** Опасная бритва уже есть в её логотипе (лиса, ножницы и бритва).
Отсюда и мотив сайта: на главном экране бронзовая линия «режет» экран, и фото открывается по этому срезу.
Секции стыкуются косыми срезами, бронзовая лента на главной идёт под углом, как полоса скотча.
Всё остальное сдержанное: одна гарнитура для заголовков, три цвета, много фото.

Вторая сильная деталь — **прайс в виде чека**. Он «печатается» из щели при прокрутке, выбранные услуги заливаются
бронзой, сумма набегает, на комбо ставится штамп «−10 €». Блок «Bez piemaksas» встроен в тот же чек
строками за 0,00 €, включая «Sarkasms», чтобы сохранить её юмор.

- **Палитра**: чёрный `#000`, уголь `#0e0c0b`, бронза `#c4805f`, тёмная бронза `#7a4630`, тёплый белый `#f3eee7`.
- **Шрифты** (лежат в `fonts/`, с латышскими ā ē ī ū č š ž ķ ļ ņ ģ): Bebas Neue для заголовков (как на её афишах), Barlow для текста.
  Рукописный «LapsaBarber» не набирается шрифтом: это её логотип, вырезанный из афиши (`img/logo.png`, `wordmark`, `fox`).
- **Чего сознательно нет**: одинаковых карточек с тенями и скруглениями, градиентных пятен, нумерации 01/02/03,
  капс-ярлыков над заголовками, стрелок на кнопках, одинакового fade-up на каждом блоке.

### Анимации (GSAP 3.12.5 + ScrollTrigger, лежат локально в `js/vendor/`)
1. **Интро**: бронзовая линия чертится по диагонали → фото раскрывается по срезу → заголовок выезжает построчно из-под маски → кнопки.
2. Главный экран при прокрутке: фото уходит медленнее текста (параллакс).
3. Лента «Vīriešu griezumi 🦊 …» бежит сама, ускоряется и меняет направление вместе с прокруткой.
4. Манифест: слова «зажигаются» по мере прокрутки.
5. Чек «печатается» из щели; заливка выбранных строк, набегающая сумма, штамп комбо, зачёркнутая цена бороды.
6. Работы: на десктопе закреплённая горизонтальная лента с инерцией, на телефоне свайп с прогресс-линией; фото открываются на весь экран (стрелки, свайп, Esc).
7. Команда: огромные «LAURA» и «ARMANDS» едут навстречу друг другу, фото раскрывается из рамки.
8. «Mazie džeki arī»: фото открываются снизу, как жалюзи.
9. Адрес выезжает из-под маски.
10. Только на десктопе с мышью: магнитные кнопки и свой курсор («Skatīt» над работами).

Анимируются только `transform`, `opacity` и `clip-path`. При `prefers-reduced-motion` вся декоративная анимация
отключается и контент виден сразу. Если скрипты не загрузятся, страница через 3,5 с показывается без анимации.

## Как менять цены, услуги, фото

Всё, что меняется, лежит в **`content.json`**: цены, услуги, «Bez piemaksas», галерея работ, команда, ссылки.
- Цена: поменять число в `"price"`. `"from": true` значит «no … €».
- Комбо: блок `"combo"` (какая стрижка + какая услуга = сколько вместе). Экономия на штампе считается сама.
- Новое фото в галерею: положить файл в `img/` (webp или jpg, около 1000 px по ширине) и добавить строку в `"works"`.
- После правки проверить, что это валидный JSON (запятые и кавычки), например на jsonlint.com.

Тексты главного экрана, манифеста и контактов находятся прямо в `index.html`.

**Важно:** `content.json` загружается через `fetch`, поэтому при открытии `index.html` двойным кликом цены не появятся.
На Netlify и на любом локальном сервере всё работает.

## Как выложить на Netlify (около 5 минут)
1. Зайти в аккаунт Laura на https://app.netlify.com → **Add new site → Deploy manually**.
2. Перетащить папку `lapsabarber-site` целиком.
3. **Site configuration → Change site name** → `lapsabarber` (адрес будет `lapsabarber.netlify.app`).
4. Если адрес будет другим, заменить `lapsabarber.netlify.app` в `index.html` (canonical, og:url, og:image, JSON-LD).

Или через CLI: `netlify deploy --prod --dir lapsabarber-site --site <ID сайта>`.

## Админ-панель (Decap CMS)
Готово: `admin/index.html` + `admin/config.yml`. Поля повторяют `content.json` по-латышски: цены, услуги, фото, команда.
Decap хранит правки в Git, поэтому сайт при drag-and-drop работать с ней **не будет**. Чтобы включить:
1. Создать GitHub-репозиторий (лучше на аккаунте Laura) и загрузить туда эту папку.
2. В Netlify: **Add new site → Import from Git** → этот репозиторий (без команды сборки, publish directory `/`).
3. На GitHub: **Settings → Developer settings → OAuth Apps → New**: callback `https://api.netlify.com/auth/done`.
   Client ID и Secret добавить в Netlify: **Site configuration → Access & security → OAuth → Install provider → GitHub**.
4. В `admin/config.yml` заменить `repo:` на `ВЛАДЕЛЕЦ/ИМЯ-РЕПО`.
5. Laura открывает `https://lapsabarber.netlify.app/admin/`, входит через GitHub и меняет цены и фото.
   После «Publish» сайт обновляется сам примерно за минуту.

Пока шаги не выполнены, `/admin/` показывает только экран входа. Сайт при этом работает.

## Проверено
- Ширины 390 / 768 / 1024 / 1440: горизонтальной прокрутки нет.
- Консоль без ошибок, CLS = 0.
- Lighthouse (мобильный, локальный сервер без gzip): Performance 90, Accessibility 100, Best Practices 100, SEO 100.
- Прайс: 35 → +борода = 50 (штамп) → длинные 45+25 = 70 → +камуфляж «no 85» → снять стрижку «no 40».
